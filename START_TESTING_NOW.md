## 🆘 IF SOMETHING BREAKS

### Page Won't Load:
```
1. Check Terminal 1 - Is backend running? (Server listening on port 3000)
2. Check Terminal 2 - Is frontend running? (Local: http://localhost:5173)
3. Check browser console (F12 → Console tab) for errors
4. Hard refresh (Ctrl+Shift+R)
```

### Tab Shows Blank:
```
1. Open DevTools (F12)
2. Go to Network tab
3. Refresh page
4. Look for 404 errors
5. Check Console for error messages
6. Take screenshot of error
```

### API Endpoint Returns Error:
```
1. Check backend terminal for error messages
2. Look at Network tab - what's the response?
3. Is authentication token being sent?
4. Check server logs
```
